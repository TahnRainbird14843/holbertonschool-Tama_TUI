This repo is for an independent project using python curses, it will implement a game of chess in the graphical display terminal

## Current Usage
run main.py using "python3 main.py"
It will display the starting chess board position
Use standard chess notation inputs to move; for instance, if one wants to move the e pawn
first select it with e2\n then move it up two spaces with e4\n. The game now supports all moves,
its main limitation is that it does not scan for checks, so it is possible to make illegal moves
resulting in a King capture.

## Current Limitations
legal king moves/check, checkmate and not supported yet
