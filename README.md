This repo is for an independent project using python curses, it will implement a game of chess in the graphical display terminal

##Current Usage
run main.py using "python3 main.py"
It will display the starting chess board position, capital letters are for white, lowercase for black
Use standard chess notation inputs to move pawns, for instance, if one wants to move the e pawn
first select it with e2\n then move it up two spaces with e4\n

##Current Limitations
Capturing is not supported, no movement except pawns moving forward is supported
opposing pawns can move through each other
